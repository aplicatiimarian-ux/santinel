HOW TO GET NEON CONNECTION STRING:
───────────────────────────────────

1. Go to: https://console.neon.tech
2. Log in with GitHub (if not logged in)
3. Click your project: "restless-meadow-44588901"
4. Left sidebar → "Connection string" (or similar)
5. Copy the PostgreSQL connection string
6. Paste it when the script asks for it


HOW TO CREATE RENDER WEB SERVICE:
─────────────────────────────────

When the script opens https://dashboard.render.com:

1. Click: 【+】 NEW → Web Service
2. Select: GitHub
3. Choose: "santinel" repository
4. Click: Connect
5. Fill in:
   • Name: santinel-backend
   • Environment: Python 3
   • Region: Oregon (default, or closest to you)
   • Build Command:  pip install -r requirements.txt
   • Start Command: uvicorn start_api:app --host 0.0.0.0 --port $PORT
6. Click: Environment Variables (Add All)
   Copy from your .env file:
   • JWT_SECRET
   • JWT_ACCESS_TTL_MIN = 15
   • JWT_REFRESH_TTL_DAYS = 7
   • AUTH_DATABASE_URL (the Neon URL you pasted earlier)
   • CORS_ORIGINS
   • AUTH_COOKIE_SECURE = true
   • DEEPGRAM_API_KEY
   • DEEPGRAM_STT_MODEL = nova-2
   • DEEPGRAM_MIN_CONFIDENCE = 0.55
7. Click: Create Web Service
8. Wait 3-5 min for deployment
9. Copy the URL when it's ready (e.g., https://santinel-backend-xyz.onrender.com)
10. Paste it back into the script when asked

IF SOMETHING GOES WRONG:
───────────────────────

Cold start delay (first request slow):
  → Free tier Render sleeps after 15 min
  → Solution: Upgrade to paid ($7/month) or just retry

Database connection error:
  → Check Render logs: dashboard.render.com → santinel-backend → Logs
  → Verify AUTH_DATABASE_URL in env variables
  → Check Neon is accessible from Render (firewall rules)

Login still failing:
  → Check browser console (F12 → Console) for errors
  → Verify CORS_ORIGINS in Render env includes both:
    • https://santinel-8a53.vercel.app
    • https://santinel-backend-[xyz].onrender.com

Vercel not redeploying:
  → Check vercel.com dashboard
  → May take 2-5 min
  → Manual trigger: git push origin main again
